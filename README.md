# 你以为我会点什么

两个人、一部手机，把麦当劳单品和套餐拖进托盘，搭自己的餐，再猜朋友会怎么点。揭晓后留下一张带餐单的双人合影。

[在线体验](https://sanliang.online/lab/play/guess-my-order/)

![游戏封面](public/assets/cover.png)

适合一起吃饭的朋友、情侣和家人。无需注册游戏账号；餐单和价格通过服务端麦当劳 MCP 查询，照片只在设备上处理。体验站独立维护，开源版界面以本仓库为准。

## 本地运行

需要 Node.js 22.9 或更高版本。

```sh
npm ci --ignore-scripts
npm run dev
```

打开 http://127.0.0.1:18426/lab/play/guess-my-order/ 。开发模式使用明确标记的模拟餐单，不需要密钥，限本机访问。没有数据库、构建步骤或运行时大模型。

真实模式：由账号本人在 [麦当劳开放平台](https://open.mcd.cn/mcp) 开通 Token，在 [腾讯位置服务](https://lbs.qq.com/) 开通 WebService Key；复制 `.env.example` 为 `.env`，填写自己的凭证，执行 `chmod 600 .env` 后 `npm start`。凭证仅在服务端使用，不要提交 `.env`。腾讯 Key 需配置服务出口 IP，并为关键词提示、坐标转换和逆地址解析分配额度。

```sh
npm test
```

## 怎么玩

1. 填两人昵称，搜索地点或使用 GPS，确认地点后选门店及参考预算。
2. A 搭自己的托盘，再猜 B 的餐；封存后交给 B，B 同样选两次。
3. 每盘最多六份购买项，套餐整组算一份，可以换配和重复买。超预算仍能加入，只提示差额。点按、拖动和键盘都可操作。
4. 一起揭晓，按实际食物编码、规格及数量比较；同样食物单点或套餐取得都算猜中。
5. 拍照或选相册，调整取景并导出 1080 × 1620 图片；也可跳过照片。复制完整餐单，重新核价或再玩一局。

游戏提供点餐参考，不创建订单、不支付、不使用私人优惠券或积分。报价保留门店及账号适用条件，最终价格以官方渠道结算为准。

## 结构与部署

- `server.mjs`：HTTP、输入验证、缓存、限流和静态文件。
- `mcp.mjs` / `places.mjs`：真实餐单、搭配核价、地点验证。
- `public/`：原生 HTML/CSS/JavaScript、游戏状态、托盘、插画与 Canvas 合影。
- `test/`：16 项 Node 内置检查，覆盖状态、比较、预算、组合、恢复、缓存与定位校验。
- [部署示例](deploy/README.md)、[MCP 接入](MCP_INTEGRATION.md)、[验收记录](ACCEPTANCE.md)、[技术交接](HANDOFF.MD)。

昵称与答案保存在当前浏览器会话；刷新后照片需重选。封存用于同机游戏交接，不是防止设备拥有者读取浏览器存储的加密机制。服务只接受签发的地点、商品和搭配 ID；不开放任意 MCP 代理。缓存五分钟、上游最多两个并发，不记录凭证、照片或坐标。

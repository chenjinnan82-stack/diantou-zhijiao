# 你以为我会点什么

**一起吃过那么多次，这次能猜对吗？**

一部手机，两个人。把自己想吃的放进托盘，再替朋友猜一盘。交换手机，封好答案，一起揭晓——汉堡猜中了，饮料呢？最后拍张合影，把这顿饭做成一张大头贴。

[开始体验](https://sanliang.online/lab/play/guess-my-order/) · [看看怎么玩](#怎么玩) · [本地运行](#本地运行)

![你以为我会点什么：我想吃的，和你猜的](public/assets/cover.png)

适合约好一起吃饭的朋友、情侣和家人。无需注册游戏账号，约 3–5 分钟一局，拍照另计。

## 真实餐单，自己搭配

- **按门店选餐**：先确认地点和门店，再查询可售单品、套餐、随心配与分享餐。实际供应随门店和时段变化。
- **把餐放进托盘**：拖动或点按加入，套餐整组摆放，按真实选项换饮料、配餐和规格。预算只作参考，超出仍可继续。
- **猜的是朋友的选择**：双方使用同一份餐单，逐项比较主餐、配餐和饮料；不编造默契分数或人格标签。
- **留一张合影餐单**：照片在设备上取景和生成，支持保存图片；浏览器支持时可调用系统分享。

![托盘选餐界面，图中为明确标记的开发测试餐单](docs/menu.jpg)

图中餐单仅用于开发演示，不代表真实可售商品或报价。体验站独立维护，开源版界面以本仓库为准。

## 本地运行

需要 Node.js 22.9 或更高版本。

```sh
npm ci --ignore-scripts
npm run dev
```

打开 http://127.0.0.1:18426/lab/play/guess-my-order/ 。开发模式使用明确标记的模拟餐单，不需要密钥，限本机访问。没有数据库、构建步骤或运行时大模型。

### 使用真实门店和菜单

由账号本人在 [麦当劳开放平台](https://open.mcd.cn/mcp) 开通 Token，在 [腾讯位置服务](https://lbs.qq.com/) 开通 WebService Key；复制 `.env.example` 为 `.env`，填写自己的凭证：

```sh
cp .env.example .env
# 在本机编辑 .env，填入自己的 Token 和 Key
chmod 600 .env
npm start
```

凭证仅在服务端使用，不要提交 `.env`。腾讯 Key 需配置服务出口 IP，并为关键词提示、坐标转换和逆地址解析分配额度。

检查代码：

```sh
npm test
```

## 怎么玩

1. 填两人昵称，搜索地点或使用 GPS，确认地点后选门店及参考预算。
2. A 搭自己的托盘，再猜 B 的餐；封存后交给 B，B 同样选两次。
3. 每盘最多六份购买项，套餐整组算一份，可以换配和重复买。超预算仍能加入，只提示差额。点按、拖动和键盘都可操作。
4. 一起揭晓，按实际食物编码、规格及数量比较；同样食物单点或套餐取得都算猜中。
5. 拍照或选相册，调整取景并导出 1080 × 1620 图片；也可跳过照片。复制完整餐单，重新核价或再玩一局。

游戏提供点餐参考，不创建订单、不支付、不使用私人优惠券或积分。报价保留门店及账号适用条件，最终价格以官方渠道结算为准。

## 结构与部署

- `server.mjs`：HTTP、输入验证、缓存、限流和静态文件。
- `mcp.mjs` / `places.mjs`：真实餐单、搭配核价、地点验证。
- `public/`：原生 HTML/CSS/JavaScript、游戏状态、托盘、插画与 Canvas 合影。
- `test/`：Node 内置检查，覆盖状态、比较、预算、组合、恢复、缓存与定位校验。
- [部署示例](deploy/README.md)、[MCP 接入](MCP_INTEGRATION.md)、[验收记录](ACCEPTANCE.md)、[技术交接](HANDOFF.MD)。

## 隐私与使用边界

照片不上传；定位仅在点击并授权后进行，坐标交由腾讯位置服务解析，确认后的地点用于查询麦当劳门店。昵称与答案保存在当前浏览器会话；刷新后照片需重选。封存用于同机游戏交接，不是防止设备拥有者读取浏览器存储的加密机制。服务只接受签发的地点、商品和搭配 ID；不开放任意 MCP 代理。菜单与报价查询缓存五分钟，本局快照最多保留两小时；上游最多两个并发，日志仅记录接口类型、状态和耗时。

公开仓库不包含运行凭证。自部署时使用自己的密钥，并按[部署说明](deploy/README.md)配置 HTTPS 与访问来源。实测范围和未完成的手机检查见[验收记录](ACCEPTANCE.md)。
